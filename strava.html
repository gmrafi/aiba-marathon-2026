৪ প্রায়শই জিজ্ঞাসিত প্রশ্ন

🔒 Activity ID paste করা কি নিরাপদ?

১০০%। ID হলো শুধু একটা public reference number। আপনার সার্ভারে কিছুই যায় না — শুধু Strava-র নিজের strava-embeds.com/embed.js script browser থেকে public activity fetch করে iframe render করে (source)। Activity ID আপনার browser-এর localStorage-এ save হয়, "Clear" বাটনে চাপলে মুছে যায়।

🤖 "Latest Activity" কেন auto-pull হয় না?

Strava-র public embed script শুধু fixed ID render করে। সর্বশেষ activity auto-fetch করতে Strava API + OAuth দিয়ে আপনার access_token browser-এ রাখতে হতো — যেটা credential leak এবং Strava-র brand guideline-এর violation। তাই আমরা paste-and-go পদ্ধতি ব্যবহার করছি — user-friendly, secure, transparent।

⚙️ কোনো backend/relay/service আছে?

না। এই পেজটি pure static HTML — GitHub Pages / Vercel-এ হোস্ট করা। External traffic শুধুমাত্র তিনটি: (1) Google Fonts (font-face), (2) Google Analytics (analytics), (3) Strava-র নিজের public embed script (activity rendering)। কোনো proxy, Cloudflare Worker, GitHub Actions cron, বা refresh-token flow নেই।

👀 "Followers only" privacy হলে কী হবে?

অন্য user-দের কাছে "Activity not available" দেখাবে। Embed paste করার আগে Strava app → activity → "Edit" → Visibility Everyone করে save করুন।

🗑️ আমার localStorage data কীভাবে মুছব?

উপরের "Clear" বাটন চাপুন, অথবা browser DevTools Console-এ localStorage.removeItem('aiba_runner_activity_id') রান করুন।
